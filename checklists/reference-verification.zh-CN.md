# 参考文献逐条核查清单（防编造引用与七项必核规范）

> **为什么要逐条核查**：在学术专著与教材写作中（尤其涉及 AI 辅助整理、扩写或跨语种翻译时），问题引文往往披着高度逼真的学术格式外衣。最常见的四类错误包括：**真实学者姓名 + 虚构论文标题**、**完全不存在的编造 DOI**、**真实存在的 DOI 却指向另一篇毫不相干的文献（张冠李戴）**，以及**文献真实存在但原文根本不支持正文论断**。交稿前请对全书每一条参考文献逐项完成以下 7 项核查。

---

## 第 0 步：脚本批量初筛

1. 使用仓库内置的 [`tools/check_dois.py`](../tools/check_dois.py) 对 `.bib` 文献库或章节文稿执行批量核验：
   ```bash
   python3 tools/check_dois.py path/to/references.bib --strict
   ```
2. 对所有标记为 `NOT_FOUND` 的条目立即追查原始出处；若确系无据虚构条目，必须连同正文中对应的无据论断一并删除或替换为真实一手文献。
3. 对标记为 `NETWORK_ERROR` 的条目，在网络恢复后重跑确认——切勿将网络超时误判为假文献，也切勿在未复核成功前直接放行。
4. 将**不含 DOI 的文献**（纸质专著、古籍档案、国家/行业标准、学位论文、部分中文期刊或政策报告）单独列出，通过 ISBN、出版社官网、国家图书馆目录、CNKI/万方、WorldCat 或 Google Scholar 逐条人工核实。

---

## 第 1 步：单条文献七项必核清单

对全书文献表中的**每一条引用**逐一核对以下 7 项：

### 1. 作者 / 编者（Authors / Editors）
- [ ] 所有作者姓氏、名字或缩写拼写与原出版物完全一致，无拼写错漏或张冠李戴。
- [ ] 作者署名先后顺序与原文一致；符合目标体例对 `等` / `et al.` 省略人数的规定。
- [ ] 引用编著论文集（Edited Volume）中的单篇章节时，明确区分了“析出文献作者”与“全书主编（主编 / Ed. / Eds.）”。
- *AI 幻觉高发点*：大模型极易把同一领域两位从未合作过的真实知名学者拼凑成一篇虚构论文的合著者。

### 2. 标题与副标题（Title & Subtitle）
- [ ] 主标题与副标题逐字核对无误，无同义改写、缺词或语序颠倒。
- [ ] 标题中的专有名词大小写、拉丁学名斜体、化学式上下标或数学符号准确无误。
- [ ] 引用非第一版图书时，已准确注明版次（如 `第 4 版` / `4th ed.`），避免因版次不同导致页码与内容失准。
- *AI 幻觉高发点*：若某篇文献标题恰好完美复述了你正文那句话的关键词组合，极有可能是模型顺着正文倒推编造出的假标题。

### 3. 出版年份（Publication Year）
- [ ] 出版年份与正式定稿版本（Version of Record）一致，全书统一区分“在线优先发表年份（Online First）”与“正式卷期年份”。
- [ ] 正文括号内标注的年份（如 `张某某（2021）` 或 `Smith (2021)`）与文末参考文献列表年份完全一致。
- [ ] 同一作者同一年份的多篇文献已在正文和文献表中统一加注字母区分（如 `2021a`、`2021b`）。
- [ ] 早期引用的预印本（arXiv、bioRxiv、SSRN 等）若已正式在同行评议期刊或会议发表，已更新为正式出版版本信息。

### 4. 期刊、会议或出版社（Journal / Conference / Publisher）
- [ ] 期刊名称真实存在，且全书统一使用期刊全称或标准缩写（如 ISO 4 标准缩写），不混用。
- [ ] 会议论文准确著录会议名称与出版机构（如 ACM、IEEE、PMLR、ACL）。
- [ ] 专著、教材或译著准确著录出版社全称（及目标出版规范要求的出版地，译著核对译者姓名）。
- *AI 幻觉高发点*：警惕把两本真实期刊名称头尾拼接而成的“合成假期刊名”。

### 5. 卷、期、页码 / 文章号 / ISBN（Volume, Issue, Pages）
- [ ] 期刊卷号（Volume）、期号（Issue）及起止页码（如 `436–444`）或电子文章编号（Article Number）与官网/Crossref 记录完全吻合。
- [ ] 论文集析出章节已标明该章在全书中的起止页码。
- [ ] 无 DOI 的中外文图书已核实 ISBN 书号。
- *AI 幻觉高发点*：即使论文标题和作者完全真实，大模型凭记忆填写的卷期号和起止页码也经常出错，必须以数据库记录为准。

### 6. DOI 能否解析且指向同一篇文献（DOI Resolution & Match）
- [ ] DOI 可正常解析（`check_dois.py` 返回 `FOUND`，或访问 `https://doi.org/<DOI>` 正常跳转至出版商页面）。
- [ ] **关键复核**：DOI 解析出的 Crossref/出版商记录，其**标题、作者、年份**与你本地文献条目完全一致（严防“借用真 DOI 包装假文献”的移花接木错误！）。
- [ ] 全书 DOI 著录格式统一（统一写成 `https://doi.org/10.xxxx/...` 链接形式，或统一按出版社体例书写）。

### 7. 内容是否真的支持正文论点（Claim–Source Alignment）
- [ ] **确已阅读原文**：作者本人已打开并阅读所引论文、专著章节或原始数据报告，而非仅凭摘要片段或他人转引猜测内容。
- [ ] **实质支撑论点**：原文在对应段落确实得出了正文所引述的理论判断、实验结论或经验规律，不存在过度引申或强行挂靠。
- [ ] **无立场颠倒**：未将原作者在引言/综述中“引述并批判的反方观点”误当作原作者本人的学术主张加以引用。
- [ ] **数据与直接引语零误差**：凡涉及直接引语、样本量、效应量、统计显著性指标、年代或公式，均与原文逐字核对无误，并在草稿台账中记录具体页码、表号或节号（如 `pp. 105–107`、`Table 3`）。
- [ ] **溯源一手文献**：若某篇综述仅转述了更早的一手原创研究，已回溯核实并直接引用原始文献（或同时注明原始文献与综述）。

## 第 2 步：全书正文与参考文献表双向清点

- [ ] 正文中出现的每一处引用，在章末或书末参考文献表中均有唯一对应条目（无“有引无列”遗漏）。
- [ ] 参考文献表中的每一条文献，在正文中均有实际引用（除非体例明确要求单列“延伸阅读 / Further Reading”并单独分栏标注）。
- [ ] 已清理同一篇文献因不同引用键（如 `@smith2020` 与 `@smith_2020_ml`）导致的重复著录。
- [ ] 核心实证支撑文献已排查撤稿（Retraction）或重大勘误（Erratum / Correction）记录。
